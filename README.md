# 🎓 Корпоративный портал вуза (Модуль автоматизации учебного процесса)

## Описание проекта

Проект представляет собой ключевые модули корпоративного портала, разработанные в рамках Выпускной Квалификационной Работы (ВКР) с целью автоматизации учебного процесса. В частности, реализованы **Модуль «Расписание»** и **Модуль «Электронная ведомость»**. Система обеспечивает персонализированный и безопасный доступ к актуальной информации для двух основных ролей: **Студент** и **Преподаватель**.

## 🛠 Технологический стек

Проект реализован на классическом стеке **LAMP/XAMPP**.

| Категория | Технология | Назначение |
| :--- | :--- | :--- |
| **Backend / Логика** | **PHP 8.x** | Обработка запросов, бизнес-логика и контроль доступа. |
| **База данных** | **MySQL / MariaDB** | Хранение данных (расписание, пользователи, оценки). |
| **Frontend / Интерфейс** | **HTML5, CSS3** | Структура и стилизация интерфейса. |
| **Динамика / API** | **JavaScript, AJAX** | Асинхронная загрузка данных и клиентская валидация. |

## 📂 Структура репозитория
Данная структура отражает текущую архитектуру проекта:

```directory
/university_portal
├── /api             # Серверные скрипты обработки данных (JSON API)

```
## Развертывание и запуск

Для локального запуска проекта необходим установленный локальный сервер, такой как **XAMPP**, **Laragon** или **Docker**.

### 1. Требования

* PHP >= 8.0
* MySQL/MariaDB
* Веб-сервер (Apache/Nginx)

### 2. Инструкция по установке

1.  **Клонирование репозитория:**
    ```bash
    git clone [https://github.com/ваш_аккаунт/название_проекта.git](https://github.com/ваш_аккаунт/название_проекта.git)
    cd название_проекта
    ```

2.  **Настройка БД:**
    * Создайте пустую базу данных (`university_portal`).
    * Импортируйте схему и тестовые данные:
        ```bash
        mysql -u [ваш_пользователь] -p university_portal < db/schema.sql
        ```

3.  **Конфигурация:**
    * Отредактируйте файл `/includes/config.php`, указав актуальные учетные данные для подключения к БД:
        ```php
        define('DB_USER', 'ваше_имя_пользователя');
        define('DB_PASS', 'ваш_пароль');
        ```

4.  **Запуск:**
    * Убедитесь, что ваш веб-сервер настроен на обслуживание директории `/public/`.
    * Откройте в браузере: `http://localhost/путь_к_проекту/index.php`.
