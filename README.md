🎓 Корпоративный портал вуза (Модуль автоматизации учебного процесса)Описание проектаПроект представляет собой ключевые модули корпоративного портала, разработанные в рамках Выпускной Квалификационной Работы (ВКР) с целью автоматизации учебного процесса, а именно: Модуль «Расписание» и Модуль «Электронная ведомость».Система обеспечивает персонализированный и безопасный доступ к актуальной информации для двух основных ролей: Студент и Преподаватель.🛠 Технологический стекПроект реализован на классическом стеке LAMP/LEMP с использованием паттерна MVC (Model-View-Controller) для разделения логики и представления.КатегорияТехнологияНазначениеBackend / ЛогикаPHP 8.xЯзык программирования, реализующий бизнес-логику и контроль доступа.База данныхMySQL / MariaDBРеляционная СУБД для хранения данных о пользователях, расписании и оценках.Frontend / ИнтерфейсHTML5, CSS3Структура и стилизация пользовательского интерфейса.Динамика / APIJavaScript, AJAXАсинхронная загрузка данных (например, расписания) и клиентская валидация форм.🏗 Структура проектаКод организован по принципу MVC (Model-View-Controller) для обеспечения модульности и сопровождаемости./
├── app/
│   ├── config/             # Настройки приложения (settings.php)
│   ├── Controllers/        # Логика обработки запросов (AuthController, ScheduleController и др.)
│   ├── Models/             # Логика взаимодействия с БД (UserModel, ScheduleModel и др.)
│   ├── Views/              # Шаблоны HTML для отображения данных
│   └── functions.php       # Вспомогательные функции (helpers)
├── db/
│   └── schema.sql          # Схема БД и тестовые данные
├── public/
│   ├── css/
│   ├── js/
│   └── index.php           # Точка входа в приложение (роутер)
└── README.md
🚀 Развертывание и запускДля локального запуска проекта необходим установленный локальный сервер (например, XAMPP, Laragon или Docker).1. ТребованияPHP >= 8.0MySQL/MariaDBВеб-сервер (Apache/Nginx)2. УстановкаКлонирование репозитория:Bashgit clone https://github.com/ваш_аккаунт/название_проекта.git
cd название_проекта
Настройка БД:Создайте пустую базу данных с именем, указанным в файле конфигурации (по умолчанию university_portal).Импортируйте схему и тестовые данные из файла db/schema.sql.Конфигурация:Отредактируйте файл app/config/settings.php, указав свои данные для подключения к базе данных (DB_USER, DB_PASS).Запуск:Разместите проект в корневой директории вашего локального сервера.Откройте в браузере http://localhost/название_проекта/public/.🔑 Тестовые учетные записиДля проверки функционала используйте следующие тестовые учетные записи (данные из db/schema.sql):РольЛогинПарольСтудентstudent1passwordПреподавательteacher1password
